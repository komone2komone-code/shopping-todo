# 買い物＆TODO＆メモ

スマートフォン向けのシンプルな「買い物リスト」「TODOリスト」「メモ」のWebアプリ（PWA）です。  
HTML / CSS / JavaScript のみで動きます（外部ライブラリなし）。

## ファイルの役割

| ファイル | 役割 |
|---------|------|
| `index.html` | 画面の骨格（入力欄・一覧・メモ・下部タブ・アイコン） |
| `style.css` | 見た目・スマホ向けレイアウト・色分け |
| `script.js` | 追加・保存・音声入力・タブ切替・Service Worker制御 |
| `manifest.json` | ホーム画面追加・単独表示のためのアプリ情報 |
| `service-worker.js` | 本番環境でオフライン利用のためのキャッシュ |
| `icons/` | PWA用アイコン（192px / 512px） |

## 主な機能

- **買い物リスト**：追加 / 購入済みチェック / 削除 / 購入済みまとめて削除
- **TODOリスト**：追加 / 完了チェック / 削除 / 完了済みまとめて削除
- **メモ**：自由記述の複数行メモ（入力のたびに自動保存）/ メモ消去
- **音声入力**：買い物・TODO・メモで日本語音声入力（Chrome推奨）
- データは `localStorage` に保存（閉じても残る）

## 開発中の注意（Service Worker）

`localhost` や `127.0.0.1` で開いているときは、開発用に Service Worker を**登録しません**。  
古いキャッシュが残っている場合は、自動的に解除されます。

本番環境（それ以外のURL）では、これまでどおり PWA とオフライン機能が使えます。

## Live Server で確認する方法

1. Cursor でこのフォルダを開く
2. 拡張機能 **Live Server** をインストールする
3. `index.html` を右クリック → **Open with Live Server**
4. ブラウザで `http://127.0.0.1:5500` などが開く

### 確認ポイント

- 下部の「買い物」「TODO」「メモ」が1行で表示される
- 買い物・TODOの追加・チェック・削除が動く
- メモを書いて再読み込みしても残る
- マイクボタンを押すと「聞き取り中…」と表示される（対応ブラウザのみ）
- 再読み込みしても買い物・TODOのデータが消えない

### スマホで見る

1. PCとスマホを同じ Wi-Fi に接続
2. `ipconfig` で PC の IPv4 アドレスを確認
3. スマホの Chrome で `http://（PCのIP）:5500` を開く

## Android Chrome でホーム画面へ追加

1. Chrome でアプリの URL を開く
2. **⋮** → **ホーム画面に追加** または **アプリをインストール**
3. ホーム画面のアイコンから起動する

## データの保存場所

- 買い物：`localStorage` の `shoppingItems`
- TODO：`localStorage` の `todoItems`
- メモ：`localStorage` の `memoText`

ブラウザのデータを消すと内容も消えるので注意してください。

## バックアップ

メモ画面の一番下「データのバックアップ」から、買い物・TODO・メモをまとめて JSON ファイルに書き出せます。

- 書き出し：端末内に `shopping-todo-backup-YYYY-MM-DD.json` をダウンロード
- 読み込み：JSON を選ぶと確認後に現在データを置き換え（失敗時は変更しません）
- 外部サーバーには送信しません

### パソコンでの確認

1. Live Server でアプリを開く
2. メモ画面 → 「バックアップを書き出す」→ JSON がダウンロードされる
3. 「バックアップを読み込む」→ その JSON を選ぶ → 確認で OK

### Android（Chrome / Brave）での確認

1. メモ画面 → 「バックアップを書き出す」→ ダウンロードフォルダ等に保存
2. 「バックアップを読み込む」→ ファイル選択で JSON を選ぶ → 確認で OK
